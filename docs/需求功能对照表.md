# 需求功能对照表

依据《附件1：价格清单》1.2 报价明细表逐项对照（价格不涉及）。
路径说明：`S` = server/app，`C` = client/xiaoxin_client，`A` = 管理端菜单，`H5` = 运维移动端。

## 一、小信助手桌面客户端（client/）

| 二级/三级模块 | 四级模块 | 实现位置 | 说明 |
|---|---|---|---|
| 一键提速/垃圾清理 | 垃圾文件扫描 | `C/cleaner.py` | Linux：APT（clean/autoclean/autoremove/软件包列表）、Bash 历史、/tmp、/var/tmp、/var/log、~/.xsession-errors、~/.cache、/var/cache、回收站；Windows：%TEMP%、Windows\Temp、日志、更新缓存、Prefetch、浏览器缓存等 |
| | 垃圾文件清理 | `C/ui_speedup.py JunkFrame` | 一键清理，树状分类（双击勾选），右键打开详细信息窗口列出具体文件，进度条显示扫描/清理进度；需 root 的项目用 pkexec 图形授权 |
| 一键提速/内存加速 | 进程可视化 | `C/procmgr.py`、`ProcessFrame` | 实时 CPU/内存/网络/磁盘 曲线；进程列表按 CPU、内存、网络连接数、磁盘 IO 排序 |
| | 进程优化 | `procmgr.find_idle / kill` | 一键识别闲置进程（长时间无 CPU/网络/磁盘活动、占用内存、非关键进程），确认后结束 |
| 一键提速/大文件检索 | 本机文件扫描 | `C/bigfile.py` | 扫描大于 100MB（可调）的文件，跳过系统虚拟目录 |
| | 扫描进度 | `BigFileFrame` | 进度、当前文件、文件名/大小/更新时间、按类型统计 |
| | 删除清理 | `BigFileFrame` | 勾选 / 全选 删除，打开所在目录 |
| 探针监测升级/配件更换监测 | 配件信息采集 | `C/sysinfo.py` | CPU、核数、内存、硬盘容量/型号、操作系统、品牌、型号、序列号、MAC、架构；飞腾/鲲鹏通过 CPU implementer 识别 |
| | 更换状态提醒 | `C/agent.py`、`S/services/monitor.py` | 本地与服务端双重对比历史配件信息，弹窗提醒并上报，管理端『配件更换监测』确认 |
| 探针监测升级/设备信息监测 | 监测指标管理 | `S/services/monitor.compute_indicators` | 按使用人、CPU、内存、硬盘、操作系统、利用率等计算接入率、替代完成率、双轨率、活跃率、违规双系统；客户端启动时执行双系统检测 |
| | 监测指标可视化预警 | A『监测指标与预警』 | 阈值可配置，异常/不合规指标标红预警，列出违规终端 |
| 悬浮助手 | 悬浮助手 | `C/floating.py` | 置顶可拖动悬浮图标，单击唤醒智能问答，右键菜单，消息红点 |
| 智能问答/多模型切换 | 路由策略 | `S/llm/router.py` | 统一调用接口，优先级+自动降级/轮询/加权/按场景；用户可在客户端下拉切换 DeepSeek、星辰、Qwen 等 |
| | 配置与管理 | A『模型接入与配置』 | 动态增删模型、配置路由策略，读库即时生效无需重启 |
| | 模型调用接口 | `S/llm/adapters.py` | DeepSeek/Qwen/星辰(TeleChat)/OpenAI 兼容/本地兜底 各一个适配器，统一请求与响应格式，支持流式 |
| 智能问答/多轮问答 | 会话标识 | `S/api/llm.py` ChatSession | 每个会话唯一 Session ID，超时自动销毁（可配置） |
| | 上下文存储与管理 | `_history()` | 对话历史列表，滑动窗口保留最近 N 轮，可选“滑动窗口+历史摘要” |
| | 状态跟踪 | `_state_tracking()`、A『状态跟踪(意图槽位)』 | 意图+槽位配置，持续追问直至必要参数收集完毕（内置“故障报修”自动创建工单，另含会议室预订示例） |
| 智能问答/文本问答 | 本地知识问答 | `ChatFrame` 本地知识问答模式 | 上传私有 PDF/Word/TXT 等进入个人知识库，问答输出，可暂停/继续 |
| | 文本向量化 | `S/services/rag.py embed` | 文本分片→向量→存入 PostgreSQL（kb_chunk） |
| | 检索增强生成 | `rag.search / build_prompt` | 查询向量化、相似度检索 TopK、构造增强提示词发送大模型 |
| 合同智审 | 合同上传 | `ContractFrame`、`S/api/contract.py` | 支持 PDF、OFD（另支持 Word/Excel/PPT/图片） |
| | 合规性审查分析 | 同上 | 展示要素提取结果、合规性研判结果，不合规要素标红预警 |

| | 模型配置（参数调优、版本管理、灰度发布） | A『模型接入与配置』→ 编辑 / 发布 |

| | 模型性能监控（专业测试集，准确性/专业性/时效性评估） | A『模型评估』 |
| | 参数调整（基于结果调整超参重新微调验证） | A『模型微调』→ 调参重训 |
| 信创知识库管理 | 知识导入（多格式批量解析、OCR、版本管理/历史追溯/冲突检测、自动打标+人工校验、进度监控、断点续传、错误重试、导入日志） | `S/services/docparse.py`、`rag.process_doc`、A『知识库构建』 |
| | 数据预处理（编码识别、字符清洗、格式统一、段落结构化、无效/重复/乱码过滤） | `docparse.clean_text / is_low_quality / split_chunks` |

| | 检索结果管理（去重合并、相关性评分、上下文拼接、召回率/精确率评估、链路监控可视化） | A『检索测试与策略』『RAG链路监控』 |
| 合同智审服务 | 多格式解析（PDF/Word/OFD/Excel/PPT、表格识别、图像分离、OCR、版面结构） | `docparse.py`、`contract.split_clauses` |

| | 差异提示（模板库、条款要素定义、必选/可选、相似度+关键词比对、颜色编码） | A『合同模板库』、审查结果『模板差异』 |

| 工具与插件 | 内置工具使用（OCR、图片场景/图表分析、置信度、链式调用、参数传递、异常处理、超时控制） | `S/services/tools.py`、A『工具管理』『工具调度』 |
| | 工具性能评估（响应时间、成功率、P95、资源占用、异常告警、仪表盘） | A『工具性能评估』 |
| | 第三方工具接入（REST/GraphQL/WebSocket、API Key 认证、SDK 与文档） | `/open/v1/*`、A『插件开放平台』、`sdk/` |
