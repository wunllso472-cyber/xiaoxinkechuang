## 4. 说明

- 对外只有 `8000` 一个端口提供服务，管理端、H5、接口都在这个端口下，靠路径区分。
- 数据库为人大金仓（KingbaseES），默认端口 54321，只供服务端使用，不是访问入口；连接与 schema 配置见部署手册 2.8，可在服务器上执行 `venv/bin/python -m app.init_data --check` 查看库、schema 和表数量。
- 开发机开着代理的 TUN 模式（网卡 `Meta`），在这种环境下用 TCP 连接测试端口会全部显示“通”，结果不可信；判断服务是否可用以 HTTP 实际返回为准（上表即是）。
- `192.168.31.134` 是内网地址，只有同一局域网内的电脑、手机能访问；手机使用 H5 需连接同一网络。
